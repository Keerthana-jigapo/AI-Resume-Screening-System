# 📄 AI Resume Screening System

## 🚀 Live Demo
https://ai-resume-screening-keerthana.streamlit.app/

---

## 📌 Features

- Upload Resume (PDF)
- ATS Resume Matching Score
- Resume & Job Description Comparison
- Matched Skills
- Missing Skills
- Skills Pie Chart
- Suggestions for Resume Improvement
- Download ATS Report (PDF)

---

## 🛠 Tech Stack

- Python
- Streamlit
- Scikit-learn
- PyPDF2
- Matplotlib
- FPDF
